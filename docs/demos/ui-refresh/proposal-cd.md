# TypeK UI 刷新設計提案：兩套大膽鮮明視覺方向評估報告（Option C & D）

> **專案背景**：TypeK 是一款以 macOS 優先的桌面語音轉文字與 AI 整理應用（Tauri v2 + Vue 3 + shadcn-vue new-york + Tailwind 語意變數）。在前一輪提案 A（Native Air）與提案 B（Editorial Studio）的評審中，負責人 Kevin 給出了清晰的回饋：「都太普通了。」  
> 本提案針對「**極具辨識度、大膽且令人難忘**」的設計目標，帶來兩套截然不同且視覺張力拉滿的全新方向：
> 1. **提案 C：鵝黃復古風（Retro Gosling Yellow）** —— 70s/80s 類比音響、奶油鵝黃、焦糖暖褐、打字機字體、類比 VU-Meter 音量計與卡帶轉軸。
> 2. **提案 D：繽紛少女風（Colourful Girly Pop）** —— 夢幻草莓糖果粉、薰衣草紫、果凍氣泡圓角、貼紙徽章、璀璨星光與彩虹彈跳波形。
>
> 兩套方案均兼顧在現有技術棧（shadcn-vue + Tailwind CSS 變數）下的落地實作性，且保持全域本文對比度 ≥ 4.5:1，HUD 狀態具備圖標、文字與造型等多維回饋（不依賴單一顏色）。

### 3. 字體與裝飾手法
- **系統字體層級**：
  - 標題與品牌識別：優先呼叫系統打字機與粗襯線字型 `"American Typewriter", "Rockwell", "Courier New", "Georgia", "PingFang TC", serif`，重現 70 年代機械打字機與印刷排版力量。
  - 數據、計時器與標籤：採用等寬字體 `"SF Mono", "Menlo", "Monaco", "Courier New", monospace`，徹底消除跳動並傳遞儀表感。
  - 本文：維持乾淨易讀的 macOS 系統無襯線字體 `-apple-system, BlinkMacSystemFont, "PingFang TC", "Noto Sans TC", sans-serif`。
- **純 CSS 裝飾手法**：
  - **微半色調網點底紋（Halftone Dot Grid）**：利用 `radial-gradient(var(--border) 10%, transparent 11%)` 搭配 `background-size: 14px 14px`，零依賴圖片產生老式網點紙張肌理。
  - **復古硬陰影（Retro Drop Shadow）**：按鈕與卡片配置 `3px 3px 0px rgba(52, 33, 17, 0.22)`，懸浮與點擊時產生極具機械按鍵反饋的像素位移（Micro-displacement）。
  - **儀表虛線與印章標籤**：廣泛使用 1.5px/2px 虛線分隔條，標籤以雙重實線框搭配大寫英文刻印（如 `TAPE #041 · OK`、`REC CH-1 ONLINE`）。

### 5. HUD 設計（Notch HUD）
Notch HUD 採用沉穩的**電木黑褐（Bakelite Brown）實體外殼**，兩側點綴一字螺絲固定金屬件（Screw Accents），與螢幕硬體鏡頭缺口緊密貼合：
- **錄音中**：左側紅光呼吸圓點配搭 `REC [CH-1]`，中央配置**五段式綠／黃／紅 LED 類比 VU-Meter 音量計**，隨語音動態起伏；右側為翻頁鐘風格等寬計時器 `00:14.8`。
- **整理中**：**雙卡帶轉軸（Cassette Spools）迴旋轉動動效**，中央以打字機字體顯示「AI 磁帶分析潤色中...」，傳遞磁帶快速倒帶檢索的類比趣味。
- **已貼上**：綠色雙圓環出廠合格檢驗認證印章（Stamp Circle `✓`），右側以磁帶計數器格式標示「PASSED · 0.8s」。
- **錯誤**：紅色過載警示銘牌（`OVERLOAD !`）+「連線逾時，請檢查 API Key」，搭配「重新讀帶 ↺」電木按鈕。

### 6. 實作工作量與風險
- **實作工作量**：**M（Medium，中等）**。
- **技術風險與額外 CSS**：
  - 需在 `src/style.css` 寫入網點背景與 `--retro-shadow` 自訂變數。
  - Notch HUD 的 VU Meter 需要 5 欄簡易 flex 佈局與 LED 分段 class（純 CSS，無任何外部腳本依賴）。
  - 所有元件均由現有 shadcn-vue Card、Button、Switch 改裝而成，不破壞 Vue 邏輯。
- **適合誰**：偏好 Mid-Century 現代主義、鍵盤客製化愛好者、黑膠與音響發燒友、工程師、希望軟體帶有強烈實體硬體質感的專業工作者。
