# TypeK

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Tiếng Việt](README.vi.md) | **ไทย**

> กดค้างเพื่อพูด ปล่อยเพื่อวาง — เครื่องมือเดสก์ท็อปที่เปลี่ยนเสียงพูดเป็นข้อความเขียน

TypeK เป็นเครื่องมือป้อนเสียงบนเดสก์ท็อป ในแอปใดก็ตาม ให้กดคีย์ลัดค้างไว้แล้วพูด เมื่อปล่อย เสียงจะถูกถอดด้วย Groq Whisper จากนั้น AI จะปรับให้เป็นข้อความเขียนที่ลื่นไหล โดยอ้างอิงแอปที่คุณกำลังพิมพ์และข้อความรอบเคอร์เซอร์ แล้ววางลงที่ตำแหน่งเคอร์เซอร์โดยตรง

TypeK เป็น fork ของโปรเจกต์โอเพนซอร์ส [SayIt](https://github.com/chenjackle45/SayIt) ดัดแปลงและเผยแพร่ภายใต้[สัญญาอนุญาต MIT](LICENSE)

## ฟีเจอร์

- **จากภาษาพูดเป็นภาษาเขียน** — AI ตัดคำฟุ่มเฟือย แก้คำพ้องเสียงและเครื่องหมายวรรคตอนให้อัตโนมัติ พูดจบก็ใช้ได้เลย
- **การรับรู้บริบท** (macOS) — ขณะปรับข้อความจะอ้างอิงแอปปัจจุบัน ชื่อหน้าต่าง และข้อความรอบเคอร์เซอร์ ทำให้แก้คำเฉพาะได้แม่นยำขึ้น ช่องรหัสผ่านจะไม่ถูกอ่าน และปิดได้ในการตั้งค่า
- **คีย์ลัดทั้งระบบ** — ทริกเกอร์ได้ในแอปใดก็ตาม รองรับสองโหมด Hold / Toggle
- **พจนานุกรมคำศัพท์กำหนดเอง** — ถอดเสียงคำเฉพาะและศัพท์เทคนิคได้ถูกต้อง และเรียนรู้คำใหม่จากการแก้ไขของคุณ
- **ประวัติและสถิติ** — บันทึกการถอดเสียงทั้งหมดอัตโนมัติ ดูภาพรวมการใช้งานได้ที่ Dashboard

## การติดตั้ง

### ดาวน์โหลด

| แพลตฟอร์ม | ลิงก์ดาวน์โหลด |
|------|---------|
| macOS (Apple Silicon: M1/M2/M3/M4…) | [TypeK-mac-arm64.dmg](https://github.com/kekukeku/TypeK/releases/latest/download/TypeK-mac-arm64.dmg) |
| Windows | [TypeK-windows-x64.exe](https://github.com/kekukeku/TypeK/releases/latest/download/TypeK-windows-x64.exe) |

เวอร์ชัน macOS รองรับเฉพาะ Apple Silicon (M1/M2/M3/M4…) ตั้งแต่ 1.3.3 ไม่มีเวอร์ชันสำหรับ Mac ที่ใช้ Intel แล้ว

### ขั้นตอนการติดตั้งบน macOS

ปัจจุบัน TypeK **ยังไม่ได้ผ่านการลงนามและการรับรองจาก Apple (notarization)** ครั้งแรกที่เปิดจะถูก macOS บล็อก ซึ่งเป็นเรื่องปกติ:

1. เปิดไฟล์ `.dmg` ที่ดาวน์โหลดมา แล้วลาก **TypeK** ไปยังโฟลเดอร์ "แอปพลิเคชัน (Applications)"
2. ไปที่โฟลเดอร์ "แอปพลิเคชัน (Applications)" ดับเบิลคลิก TypeK macOS จะแสดงข้อความ "ไม่สามารถตรวจสอบนักพัฒนาได้" หรือ "Apple ไม่สามารถยืนยันได้ว่า TypeK ไม่มีมัลแวร์" ให้กด "เสร็จสิ้น (Done)" หรือ "ยกเลิก (Cancel)"
3. เปิด "การตั้งค่าระบบ (System Settings) → ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security)" เลื่อนลงไปที่ "ความปลอดภัย (Security)" จะเห็น "ถูกบล็อก TypeK" ให้กด "**ยืนยันจะเปิด (Open Anyway)**" แล้วป้อนรหัสผ่านเพื่อยืนยัน
4. หลังจากนั้นจะเปิดได้ตามปกติและไม่ถามอีก

หากพบข้อความ "TypeK เสียหายและไม่สามารถเปิดได้" ให้รันคำสั่งนี้ใน "เทอร์มินัล (Terminal)" แล้วเปิดอีกครั้ง:

```bash
xattr -dr com.apple.quarantine /Applications/TypeK.app
```

### สิทธิ์บน macOS

ครั้งแรกที่ใช้ TypeK จะขอสิทธิ์สองรายการ ต้องอนุญาตทั้งสอง:

- **ไมโครโฟน (Microphone)**: บันทึกเสียงที่คุณพูด
- **การช่วยการเข้าถึง (Accessibility)** (การตั้งค่าระบบ (System Settings) → ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security) → การช่วยการเข้าถึง (Accessibility)): ตรวจจับคีย์ลัด วางข้อความที่ตำแหน่งเคอร์เซอร์ และอ่านข้อความรอบช่องป้อนข้อมูล

เนื่องจากไม่ได้ลงนาม **หลังจากอัปเดตเป็นเวอร์ชันใหม่ สิทธิ์การช่วยการเข้าถึงอาจใช้งานไม่ได้** หากคีย์ลัดไม่ตอบสนอง ให้ไปที่รายการ "การช่วยการเข้าถึง (Accessibility)" นำ TypeK ออก (−) แล้วเพิ่มใหม่ (+) และเปิดใช้งาน

### การอัปเดต

ตั้งแต่ 1.3.0 เป็นต้นไป อัปเดตได้ในแอป: ใช้ "ตรวจสอบอัปเดต" ที่แถบด้านข้าง หรือรอการแจ้งเตือนอัตโนมัติ หากใช้ 1.2.2 หรือเก่ากว่า ให้ดาวน์โหลดเวอร์ชันใหม่แล้วติดตั้งทับหนึ่งครั้ง (ไม่ต้องลบแอปก่อน)

บน macOS TypeK ต้องอยู่ในโฟลเดอร์แอปพลิเคชันจึงจะอัปเดตอัตโนมัติได้ หากปุ่มลัดไม่ทำงานหลังอัปเดต ให้ไปที่ การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การช่วยการเข้าถึง นำ TypeK ออกแล้วเพิ่มกลับและเปิดใช้งาน

### ขั้นตอนการติดตั้งบน Windows

เมื่อรัน `.exe` หากพบข้อความ "Windows ได้ปกป้องคอมพิวเตอร์ของคุณ" ให้กด "ข้อมูลเพิ่มเติม (More info)" → "เรียกใช้ต่อไป (Run anyway)"

### สิ่งที่ต้องมีก่อนเริ่ม

- [Groq API Key](https://console.groq.com/keys) — ถอดเสียง (โควตาฟรี)
- [Gemini API Key](https://aistudio.google.com/apikey) — การปรับข้อความใช้ Gemini 3.1 Flash-Lite เป็นค่าเริ่มต้น (โควตาฟรี) หรือจะเปลี่ยนไปใช้ Groq, OpenAI หรือ Anthropic ในการตั้งค่าก็ได้

### เริ่มต้นอย่างรวดเร็ว

1. ดาวน์โหลดและติดตั้งตามขั้นตอนด้านบน
2. เปิด TypeK → หน้าการตั้งค่า → วาง API Key ของ Groq และ API Key ของ Gemini
3. ในแอปใดก็ตาม กดปุ่ม `Fn` ค้างไว้แล้วพูด เมื่อปล่อยข้อความจะถูกวางอัตโนมัติ

## สถาปัตยกรรมทางเทคนิค

```
Tauri v2 (Rust) + Vue 3 + TypeScript

  ┌──────────────────────────────────┐
  │        Tauri Backend (Rust)      │
  │  全域熱鍵 · 剪貼簿 · 輸入上下文  │
  └───────┬──────────────┬───────────┘
          │ invoke()     │ emit()
  ┌───────▼──┐    ┌──────▼───────────┐
  │   HUD    │    │    Dashboard     │
  │ 狀態浮窗  │    │ 設定/歷史/統計   │
  └──────────┘    └──────────────────┘
```

- **Frontend** — Vue 3 + TypeScript + shadcn-vue + Tailwind CSS
- **Backend** — Rust (Tauri v2)
- **AI** — Groq Whisper (เสียงเป็นข้อความ) + Gemini/Groq/OpenAI/Anthropic (ปรับข้อความ)
- **Storage** — SQLite (ประวัติ) + tauri-plugin-store (การตั้งค่า)

## การพัฒนา

### ความต้องการของสภาพแวดล้อม

- Node.js 24+
- pnpm 10+
- Rust stable
- Xcode Command Line Tools (macOS)

### คำสั่ง

```bash
# 安裝依賴
pnpm install

# 開發模式
pnpm tauri dev

# 建構
pnpm tauri build

# 測試
pnpm test

# 型別檢查
npx vue-tsc --noEmit
```

### การออกเวอร์ชัน

การอัปเดตอัตโนมัติเปิดใช้งานตั้งแต่ 1.3.0: แอปจะตรวจสอบ GitHub Releases เพื่ออัปเดต ขั้นตอนเกี่ยวกับคีย์ลงนามและการออกเวอร์ชันดูได้ที่ [docs/deployment-guide.md](docs/deployment-guide.md)

```bash
./scripts/release.sh X.Y.Z
# → 自動更新版本號、commit、tag、push
# → GitHub Actions 建構 macOS + Windows 安裝檔
# → 打包成功後自動公開 GitHub Release
```
